# C Day 78 - Second Largest Number

This C program finds the second largest distinct number among the numbers entered by the user.

## Example

Input numbers:
```text
10, 25, 15, 40, 30
```

Output:
```text
Second largest number = 30
```

## Concepts Used

- `for` loop
- `if-else` statements
- Comparison operators
- Variables
- `scanf()` and `printf()`

## How It Works

The program compares each number with the current largest and second largest values. When a new largest number is found, the previous largest becomes the second largest. Duplicate values are not treated as a separate second largest number.
